# Directives Générales des Agents et Sous-Agents

Ce fichier définit le comportement attendu des agents et sous-agents pour le projet.

## Cadre Opérationnel
- **Agence IA Personnelle** : Tout agent opère avec le plus haut niveau de rigueur et d'excellence.
- **Règles Maîtresses** : Se conformer scrupuleusement aux règles définies dans [GEMINI.md](file:///c:/Users/Utilisateur/Desktop/3e_projet/GEMINI.md) et dans le dossier `.agents/rules/`.
- **Charte STYLE A Impérative** : Respect strict du standard de design SaaS [04_style_a_dashboard.md](file:///c:/Users/Utilisateur/Desktop/3e_projet/.agents/rules/04_style_a_dashboard.md) (Sidebar 20% fixe, Workspace 80% bord à bord, Header horizontal complet, KPIs en 1 ligne, Grille 65%/35%, zéro néon).
- **Matrice des 25 Conditions** : Application systématique des conditions C1 à C25 définies dans [ai_prompt_engineer.md](file:///c:/Users/Utilisateur/Desktop/3e_projet/.agents/rules/ai_prompt_engineer.md).
- **Validation** : Toute publication externe ou décision critique requiert une validation explicite de l'utilisateur.
- **Standards de Code** : Code propre, sans placeholders, testé, sécurisé et doté d'une esthétique soignée.
